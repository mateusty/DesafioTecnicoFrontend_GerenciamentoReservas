# Sistema de Gerenciamento de Reservas

## Itens necessários:
- Node.js

## Como executar

Clone o repositório e vá para o diretório do projeto
```bash
git clone https://github.com/mateusty/DesafioTecnicoFrontend_GerenciamentoReservas.git
cd ./DesafioTecnicoFrontend_GerenciamentoReservas
```

Instale as dependências do projeto

```bash
npm install
```

Rode o projeto usando o comando:

```bash
npm run dev
```
